# 1.2.0 修订说明

- 投资、取款和账户转账允许产生负余额。购买投资与账户间转账仍属于内部资产移动，全部账户的合计资产不变。
- 日期表单使用日历选择器，禁用文本日期输入；自动规则的每月执行日从 1–31 日选项中选择。实际流水只能选择今天及过去日期，规则可以选择未来开始日期，到期日可以选择未来日期。
- 首页右侧 KPI 改为“今日预计收入”，按当前账户筛选显示今日预计利息；“预计总利息”保留。
- 月日历格显示每日预计利息，选中日期可查看每笔投资的估算明细。按日产品使用本金×年利率÷365；按月和手动产品将预计总利息按整个起止日期区间平均分摊。估算只展示，不增加现金或重复记账；起始日计入、结束/提前支取日起停止展示。
- 保留现有六种流水：一次性存款、一次性取款、固定收入、投资、自动月存、账户间转账。每笔可选附最多三张图片，也可从日历流水的“明细 / 截图”入口补充备注和截图，点击缩略图放大查看。
- 上传图片本地缩放到约 1600 像素以内、压缩为 JPEG，每张最多 1MB；图片数据直接保存到本机数据库，不依赖临时图片 URI。自动流水沿用规则截图，单笔另附图片可覆盖展示。
- 顶部钱包 → 管理 / 勾选删除账户：批量选择后，指定一个保留账户接收正/负余额、投资、规则和历史流水，再删除选中账户。历史流水备注保留原账户名称。删除全部账户会清除全部财务记录与图片，必须明确二次确认，应用设置保留。
- 新增投资可勾选“购买前从其他账户转账”，选择转账来源银行和购买银行。先按本金转账，再在购买银行扣除本金；三个关联流水在同一个数据库事务内保存，删除投资时同步撤销转账和回款。
- 按实际天数的利息只由开始/到期日期计算。“计息月数”仅在按月模式显示，“手动到期金额”仅在手动模式显示。
- JSON 完整备份包含所有截图 Base64。应用导出的 CSV 新增图片列和完整备份 Base64，恢复时覆盖全部账户、六类流水、规则、投资与图片，并先显示确认；即使没有投资，也可通过 CSV 完整恢复。旧版资产 CSV 仍支持新增导入及图片列，旧 JSON 缺少图片字段时使用空图片列表。
- 含图备份上限 48MB，图片字段总量上限 16MB。含图 CSV 应保留原文件直接恢复；表格软件可以查看普通数值列，但长 Base64 字段可能被截断，完整备份推荐 JSON。
- 使用原发行签名；versionCode=3，versionName=1.2.0。Room 1→2→3 明确迁移，新增图片字段默认空列表，保留旧数据。
