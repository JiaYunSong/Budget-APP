# Android 固定收益存款管理 App 完整开发方案

## 一、项目目标

开发一款 Android 本地单机应用，用于管理个人的：

- 活期资金
- 每月自动存款
- 定期存款
- 固定收益理财
- 到期回款
- 转存记录
- 到期时间跟踪
- 总资产统计

应用要求：

1. 全中文界面。
2. Android 原生 App。
3. 不依赖 Google Play Services。
4. 不依赖 Firebase。
5. 不需要注册账号。
6. 不需要服务器。
7. 不需要联网。
8. 所有数据保存在手机本地。
9. 支持完整数据导入、导出和恢复。
10. 支持 APK 直接安装。
11. 界面简洁、美观、现代。
12. 核心目标不是消费记账，而是“存款与固定收益资产生命周期管理”。

# 十三、自动存款执行逻辑

```text

```

```text

进入首页
修改系统日期后重新进入
```

都执行：

```text
检查所有自动存款规则
```

如果发现：

```text
上次执行：
2026-07-15

今天：
2026-10-20
```

则自动补记：

```text
2026-08-15 +3000
2026-09-15 +3000
2026-10-15 +3000
```

这样不需要：

```text
AlarmManager
WorkManager
后台常驻
推送服务
Google 服务
```

也可以保证数据正确。

# 十五、利息计算

默认使用：

```text
预计利息 =
本金
× 年利率
× 实际持有天数
÷ 365
```

即：

```text
Interest =
principal
× rate
× days
÷ 365
```

例如：

```text
本金：
50000

年利率：
1.35%

开始：
2026-10-05

结束：
2027-01-05

92天
```

计算：

```text
50000 × 0.0135 × 92 / 365
```

得到：

```text
¥170.14
```

预计到期：

```text
¥50,170.14
```

# 四十一、幂等性

非常重要：

自动结算必须保证：

```text
同一事件只能执行一次
```

例如：

# 六十五、核心业务原则

整个系统始终遵守：

```text
活期 → 定期
不是支出

定期 → 活期
不是收入

利息
才是新增资产

自动存款
是外部新增资金

提前支取
是资产转移

转存
是资产生命周期延续
```

最终 App 的核心不是“记账”，而是：

```text
清楚知道：

我现在有多少钱

其中多少是活期

多少正在定期

每一笔什么时候开始

什么时候到期

利率是多少

预计能拿多少利息

未来一个月有哪些到期

到期后去了哪里

过去是如何转存的
```

这就是本应用的最终目标。
