# 1.3.0 未来定期与转出计划

- 投资开始日期、账户间转账日期和一次性取款日期允许选择未来。外部存入、余额调整和实际提前支取仍按已发生流水记录。
- 未来投资先保存为“未来定期”，未来转出先保存为计划。尚未执行时不扣减实际活期、不增加实际定期本金、不进入月 / 年 / 全部实际流水。
- 首页和账户卡片分别显示当前活期、未来定期、未来转出、可用活期。可用活期 = 当前活期 − 未来安排预留；预留超过余额时允许显示负数。总资产仍使用实际活期与已开始的定期，预留不重复计入总资产。
- 投资前跨银行转账与购买作为一组预留：只在原转出银行预留本金，购买银行的同日转入与购买相抵，避免同笔资金重复预留。未来普通转入不提前变成可用资金。
- 首页“未来定期 / 转出计划”可取消计划并释放预留，取消未执行计划不修改实际余额。存款页增加“未来定期”状态筛选。
- 到开始日 / 转出日打开或恢复应用后执行一次。漏开多日会补执行；如果已经过到期日，会同时补记购买与本息回款。应用不操作真实银行资金，不在关闭时自动扣款。
- 预计总利息包含未来定期的整个存期收益；今日预计收入只展示当日已开始产品的利息。实际日历不混入未执行计划。
- JSON、完整 CSV 和旧版资产 CSV 支持未来计划；完整备份保留未执行状态、关联转账和图片。
- Room 3→4 增加流水执行标记，旧流水默认为已执行，防止升级重复扣款。保留 1→2→3→4 迁移链。版本为 1.3.0，沿用原发行签名。
