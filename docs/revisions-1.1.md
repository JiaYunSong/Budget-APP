# 1.1.0 修订

- 删除每月工资结余或固定收入规则时，清除该规则关联的全部流水，逐账户撤销已入账金额。资金已花费时允许显示真实负余额，删除确认会提示。
- 自动月存默认从指定开始日期持续执行，无结束日期即长期。只补记截至今天的实际发生月份。单独删除某月流水不会倒退执行游标，也不会再次补回；后续月份继续执行。
- 月视图、年视图和全部流水只展示截至今天的实际记录，各视图提供新增入口和逐条删除按钮。月视图以选中日期新增，年视图以当年 1 月 1 日为默认日期，全部流水默认今天；表单均可改日期，实际流水拒绝未来日期。
- 六个入口：一次性存款、一次性取款、固定收入、投资、自动月存、账户间转账。固定收入是每月重复的外部收入规则；投资沿用定期及固定收益资产的本金、利率和到期回款管理。
- 顶部钱包按钮创建账户或选择统计账户。选一个单独统计，选择多个合并统计，不选则展示全部账户。每笔流水选择所属账户，转账选择转出及转入账户。
- 转账删除同时撤销两端；投资删除会撤销该产品及后续转存的本金、回款流水，恢复余额和前序产品状态。旧版没有配对 ID 的同日同额转账如果存在歧义，拒绝猜测配对。
- 洛可可粉紫、奶油白、薄荷色与香槟金；低多边形生成花园素材；圆角卡片、日历格和平滑环形图。亮暗主题均保留清晰文字。
- 使用原 Release 签名，versionCode 从 1 升至 2。Room 1→2 显式迁移新增规则类型与转账配对 ID，保留旧规则、游标和流水。旧 JSON 中缺失新增字段时使用兼容默认值。

生成背景位于 `app/src/main/res/drawable-nodpi/rococo_garden.png`。应用运行无需图片生成服务或网络。
